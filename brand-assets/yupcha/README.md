# Drop real Yupcha product screenshots here

Put 1–3 PNG/JPG screenshots of the actual product UI in this folder.
The pipeline picks up everything here automatically (asset-override).

Best results — name by role so the director places them well:
  dashboard.png      → main app / dashboard (used as the hero ProductShot)
  interview.png      → an interview / candidate view (FeatureBeat)
  ranking.png        → results / ranking / scoring view (FeatureBeat)
  <anything>.png     → still used, just less targeted

Guidance:
  - High-res (≥1600px wide), clean UI, no cursors/notifications.
  - Crop to the meaningful UI; the engine frames it in browser chrome.
