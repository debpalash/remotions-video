# Drop real ResuBird product screenshots here

Put 2–4 PNG/JPG screenshots of the actual product UI in this folder.
The pipeline picks up everything here automatically (asset-override) — replacing
the synthetic mock dashboard, which is the #1 thing the judges flag.

Best results — name by role so the director places them well:
  dashboard.png   → main app / resume dashboard (hero ProductShot)
  ats-score.png   → the ATS score / analyzer view (FeatureBeat)
  editor.png      → resume editor / bullet rewriter (FeatureBeat)
  cover-letter.png→ cover-letter generator (FeatureBeat)
  <anything>.png  → still used, just less targeted

Guidance:
  - High-res (≥1600px wide), clean UI, no cursors/notifications/personal data.
  - Crop to the meaningful UI; the engine frames it in browser chrome.
  - A real "ATS score" gauge/number is gold — it makes the highlight ring land
    on something concrete instead of a mock chart.
